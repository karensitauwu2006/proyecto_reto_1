Base de datos

La base de datos de la startup tendrá como objetivo centralizar toda la información necesaria para la gestión del motor gráfico y de los servicios asociados. Entre los datos almacenados se incluirán usuarios, roles, licencias, compras del marketplace, proyectos, incidencias, versiones del motor, información económica y gestión interna de la empresa. Los archivos pesados como modelos 3D, texturas o ejecutables no se almacenarán directamente en la base de datos, sino en sistemas de almacenamiento especializados, manteniendo en la base de datos únicamente sus metadatos y referencias.

Sistema de gestion de base de datos

Hemos decidido utilizar una base de datos relacional como sistema principal de almacenamiento de información. Esta elección se debe a que la mayor parte de los datos gestionados por la empresa presentan relaciones claramente definidas y requieren altos niveles de consistencia, integridad y seguridad.

Sistema gestor de base de datos

Entre las diferentes opciones disponibles encontramos MySQL y PostgreSQL, dos SGBD relacionales que utilizan SQL y que permiten trabajar con tablas relacionadas, claves, consultas y transacciones.

Ambas opciones serían viables para nuestro proyecto, ya que permiten gestionar correctamente la estructura de datos que hemos planteado. Por tanto, no consideramos que exista una necesidad concreta de descartar uno de los dos debido a las necesidades actuales de nuestra startup.
